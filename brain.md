## ✅ Notebook 4: ECG — `04_ECG_Staging.ipynb` — COMPLETE

**Pipeline:** EDF → bandpass 0.5–40 Hz + 50 Hz notch → scipy find_peaks R-peak detection → RR intervals → 10 HRV features → DataFrame → LOSO RF + GRU

**EXECUTED — Real LOSO Results:**

| Model | Mean Acc | Macro F1 | Cohen κ | N3 F1 | REM F1 |
|---|---|---|---|---|---|
| RF (10 feat) | 21.3% | 16.0% | 0.020 | 15.7% | 14.6% |
| GRU seq=5 (64u) | 21.2% | 15.1% | 0.019 | 14.9% | 18.2% |

**Key findings:**
- `vlf` = 0.0 for ALL epochs — 30-second epochs are too short for VLF band (needs ≥250s window for 0.003–0.04 Hz resolution). Expected, not a bug.
- `hr_mean` is top feature (16.1%) — mean HR IS the dominant ECG signal in 30s windows
- RF ≈ GRU — both near random for most subjects (SN5 acc=11.5%)
- SN3 is worst (acc=19.1%, k=0.028) — AHI=17.0, frequent arrhythmic surges across all stages
- Performance lower than EMG — surprising but explained: 30s epoch destroys frequency-domain HRV
- **Fix for fusion:** 5-minute sliding HRV windows (overlapping epochs) OR use time-domain features only (hr_mean, sdnn, rmssd, pnn50, poincare_sd1, poincare_sd2 — 6 features that work at 30s)
- **Parquet saved:** `features/ecg/SN{1-5}.parquet` ✅ (5122 clean epochs × 20 cols)

**What ECG still contributes to fusion despite low solo accuracy:**
- `hr_mean` encodes absolute autonomic state — wake HR > N2 HR > N3 HR (monotonic trend RF can learn jointly with EEG/EOG features)
- `lf_hf_ratio` (REM autonomic storm) — contributes REM disambiguation when EOG saccades agree
- Time-domain features (RMSSD, SD1) will help as auxiliary features in the dual-head fusion model

- **Apnea still F1≈0** — class imbalance (4.5%) is too severe for threshold=0.5. AUC=0.53 shows latent signal.

## 🔑 Golden Rules (NEVER VIOLATE)
1. **User writes code, agent documents** — never pre-write code cells unprompted
2. **LOSO only** — never `train_test_split(shuffle=True)` on pooled epochs
3. **Assert leakage** — `assert len(train_subjects & test_subjects) == 0` in every split
4. **Both label targets** — always report metrics against hard-vote AND soft-KL labels
5. **Stage ≠ Apnea metrics** — never blend their κ or report them as one number
6. **EOG bands are ocular-specific** — document them explicitly; don't confuse with AASM EEG bands
7. **Annotation sep=","** — read with `pd.read_csv(path, skipinitialspace=True)`, never `sep="\t"`
8. **Notebooks not editable by replace_file_content** — always use Python `json` script to modify .ipynb

## 🫁 APNEA PREDICTION ARCHITECTURE & CLINICAL LOGIC

### 1. Physiological Modalities & Channel Mapping:
* **Nasal Airflow**: `resp_nasal_amp`, `flow_limit_idx`, `resp_rate` → identifies airway flow reduction / flattening.
* **Thoracoabdominal Belts**: `resp_chest_amp`, `resp_abd_amp`, `thoraco_phase`, `chest_abd_corr` → identifies paradoxing ($180^\circ$ phase shift) during obstructive respiratory effort.
* **Pulse Oximetry ($\text{SaO}_2$)**: `sao2_mean`, `sao2_min`, `sao2_drop90`, `sao2_slope`, `sao2_below92` → captures delayed oxygen desaturations following apneas.
* **Cardiovascular (ECG/HRV)**: `hr_mean`, `hrv_rmssd`, `hrv_sdnn`, `lf_hf_ratio` → detects post-apnea tachycardia and autonomic arousal surges.
* **Interaction Gates**: `apnea_gate`, `obstructive_idx`, `arousal_idx` → flags simultaneous flow reduction and persistent thoracic movement.

### 2. Multi-Scorer Consensus Ground Truth Formulation:
* Read all 12 independent scorers' annotations: `SN*_Respiration_manual_scorer1..12.txt`.
* Types evaluated: Obstructive apnea, Hypopnea, Mixed apnea, Central apnea.
* Mapped continuous interval boundaries to 30-second epoch grids using any-overlap intersection.
* **Consensus Threshold**: Epoch is labeled positive for sleep apnea if $\ge 4$ of the 12 scorers agreed.
* Positive epochs recovered: **816 consensus epochs (15.9%)** vs. 237 (single scorer).

### 3. Apnea Results Summary (LOSO LightGBM):
* **Pooled Consensus AUC-ROC**: **0.512** (up from 0.249 single-scorer failure).
* **SN3 (Severe, 33.5% Apnea Rate)**: **AUC = 0.529**, **$F_1 = 0.425$** at threshold $t = 0.05$.
* **Key Finding**: High diagnostic power on moderate-to-severe patients; mild cases require 5-minute sliding windows or continuous AHI regression.
